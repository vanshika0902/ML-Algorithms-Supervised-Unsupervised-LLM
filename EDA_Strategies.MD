- EDA stands for Exploratory Data Analysis
- Common Strategies
  - Understand the dataset (shape, data type, target variable, class imbalance)
  - Check missing values & duplicates
  - Detect outliers & unusual distributions
  - Perform univariate & bivariate analysis (summary statistics, distributions, correlations)
  - Data preprocessing (encoding, scaling, feature engineering)

Also 
  - null imputations
  - categorical encoding
  - remove redundant variables
